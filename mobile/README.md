# ДЖЕК 15: тестовое Android-приложение

Изолированный проект Capacitor 8. Исходные файлы сайта не меняются. Интерфейс копируется в APK; MIRROR_PATH только в копии направляется на действующий сайт. Доступность API и CORS в WebView требуют проверки на устройстве.

В GitHub Actions вручную запустить Android APK test. При успешной сборке артефакт dzhek15-test-apk содержит app-debug.apk. Workflow не запускается автоматически. Это тестовая debug-сборка, не production-релиз.

Ограничения: стандартная Android-иконка; экспорт и отправка CSV, внешние ссылки, обновление данных, локальное сохранение и кнопка Назад ещё не проверены. Старые данные браузера автоматически не переносятся. Возможна несовместимость веб-функций с WebView.

Debug-ключ на временном runner не сохраняется: переустановка следующей сборки может потребовать удаления предыдущей с потерей локальных данных. Не использовать для хранения единственных копий купонов. Для постоянного приложения нужны release-подпись и безопасное хранение ключа.

Сборка и работоспособность не подтверждены до фактического выполнения workflow и проверки на телефоне. APK здесь не публикуется автоматически.
