    Загрузить другой список матчей

    По матчу в строке. Разделитель команд — тире или дефис. Время, дату и лигу можно оставить в строке, они распознаются. Строка без тире считается названием лиги для следующих матчей.

    Купон и список сыгранных хранятся в этом браузере: закроешь вкладку — всё останется. Бросок ставит по одному случайному исходу в каждую строку с пометкой «рандом», выбирая только из отмеченных там исходов; строки с «фиксом» он не трогает. «Вернуть» откатывает последнее действие, «В купон» загружает любой сыгранный вариант обратно.
